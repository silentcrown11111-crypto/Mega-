MEGA SWEETS & BAKERS — DEMO WEBSITE (offline copy)
Open index.html in any modern browser (Chrome, Edge, Safari, Firefox).
Everything needed is in this folder: img/ (photos and cut-outs), lib/ (GSAP, ScrollTrigger, Three.js, Lenis).
Only the Fraunces and Manrope web fonts are fetched from Google Fonts when online; offline the page falls back to Georgia / system sans.
To host: upload the whole folder to any static host (Netlify, Vercel, cPanel public_html).
